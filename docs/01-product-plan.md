# 제품 기획

## 프로젝트 개요

이 프로젝트는 모바일 환경에 최적화된 1:1 채팅 웹앱입니다. 웹앱을 먼저 배포하고, 이후 Capacitor를 통해 Android 앱으로 확장합니다.

## 핵심 목표

1. 빠르게 배포 가능한 MVP 제작
2. 모바일 중심의 간단한 채팅 경험 제공
3. 유료 대화권 또는 포인트 기반 수익 모델 검증
4. 신고, 차단, 관리자 기능을 초기부터 고려

## MVP 범위

- 랜딩 화면
- 회원가입 / 로그인
- 프로필 생성
- 유저 목록
- 1:1 채팅
- 신고 / 차단 기본 구조
- 포인트/코인 시스템 설계

## 이후 확장 후보

- 결제 연동
- 프로필 노출 부스트
- 사진 열람권
- 관리자 검수 기능
- Android 앱 패키징
- 푸시 알림
