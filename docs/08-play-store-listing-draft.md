# 플러팅 Play Store 등록 문구 초안

이 문서는 Google Play Console 등록 정보에 사용할 문구 초안입니다. 실제 출시 전 운영자 정보, 고객지원 이메일, 개인정보처리방침 URL, 스크린샷, 앱 카테고리를 최종 확인해야 합니다.

## 앱 이름

```txt
플러팅
```

## 짧은 설명

80자 이내 권장입니다.

```txt
가볍게 시작되는 설레는 1:1 대화
```

대안:

```txt
새로운 사람과 자연스럽게 이어지는 대화
```

```txt
토크에서 시작해 1:1 채팅으로 이어지는 설렘
```

## 전체 설명

```txt
플러팅은 새로운 사람과 가볍게 대화를 시작할 수 있는 모바일 채팅 앱입니다.

짧은 토크를 남기고, 마음이 가는 사람의 프로필을 확인한 뒤 1:1 채팅으로 자연스럽게 이어질 수 있습니다. 복잡한 설정 없이 닉네임, 나이, 성별, 지역, 프로필 사진으로 간단하게 시작할 수 있으며, 최근 접속자 목록을 통해 지금 대화할 수 있는 사람을 찾아볼 수 있습니다.

주요 기능
- 한줄 토크 작성 및 확인
- 최근 접속자 목록
- 프로필 미리보기
- 1:1 채팅
- 이미지 메시지 전송
- 차단 및 신고 기능
- 20세 이상 이용자 대상 서비스

플러팅은 안전한 대화 환경을 위해 신고와 차단 기능을 제공합니다. 부적절한 이용자는 서비스 이용이 제한될 수 있습니다.

현재 플러팅은 모바일 환경에 최적화되어 있으며, 향후 더 편리한 대화 기능과 안전 기능을 계속 개선할 예정입니다.
```

## 카테고리 후보

```txt
소셜
```

또는

```txt
커뮤니케이션
```

현재 기능상 1순위는 `소셜`입니다.

## 태그/키워드 후보

Google Play에 직접 키워드 입력란은 제한적이지만 설명문과 스크린샷 문구에 참고할 수 있습니다.

```txt
채팅, 1:1 대화, 토크, 프로필, 새로운 대화, 설렘, 소셜, 친구, 커뮤니케이션
```

## 스크린샷 구성안

### 1장: 첫 인상

```txt
가볍게 시작되는 설레는 대화
```

화면 후보: 토크 탭

### 2장: 토크

```txt
한마디로 시작하는 새로운 연결
```

화면 후보: 토크 작성/목록

### 3장: 사람

```txt
지금 대화할 수 있는 사람을 만나보세요
```

화면 후보: 사람 탭/최근 접속자

### 4장: 프로필

```txt
프로필을 보고 자연스럽게 대화 시작
```

화면 후보: 프로필 미리보기 모달

### 5장: 채팅

```txt
편하게 이어지는 1:1 채팅
```

화면 후보: 채팅방

### 6장: 안전

```txt
신고와 차단으로 더 안전하게
```

화면 후보: 설정/차단 목록 또는 채팅방 신고/차단 버튼

## 그래픽 자산

```txt
앱 아이콘 원본: resources/icon.png
스플래시 원본: resources/splash.png
Play Store 앱 아이콘: 512×512 PNG 별도 추출 필요
피처 그래픽: 1024×500 PNG 별도 제작 필요
스크린샷: 휴대폰 화면 기준 최소 2장 이상 필요
```

## 개인정보처리방침 URL

Cloudflare Pages 배포 후 아래 형태가 됩니다.

```txt
https://chat-509.pages.dev/privacy.html
```

커스텀 도메인을 연결하면 해당 도메인으로 교체해야 합니다.

## 출시 전 필수 보완

- 운영자명 또는 사업자명 입력
- 고객지원 이메일 입력
- 개인정보 보호책임자 또는 문의처 입력
- 실제 인증 방식 도입 전 localStorage 기반 계정 한계 인지
- 신고/차단 UX 실기기 테스트
- 부적절 콘텐츠 대응 정책 점검
- 20세 이상 제한 문구와 심사 답변 일관성 확인
