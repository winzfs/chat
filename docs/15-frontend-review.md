## 남은 구조 개선

### 1. 마이룸 편집 화면 분리

`MyRoomSettingsPanel.tsx`는 카탈로그, 배치 편집, 저장 상태, 메뉴 렌더링을 한 파일에서 처리합니다. 아래 단위로 분리하는 것이 좋습니다.

- `useMyRoomEditor`
- `MyRoomCatalogPanel`
- `MyRoomSelectedItemPanel`
- `MyRoomAppearancePanel`
- `MyRoomEditorToolbar`

특히 상태 updater 안에서 다른 상태 setter를 호출하는 부분은 순수한 계산과 화면 상태 변경을 분리해야 합니다.

### 2. 모달 공통 컴포넌트

현재 모달마다 ESC 처리와 배경 클릭 처리가 따로 있습니다. 공통 `Modal` 컴포넌트로 포커스 가두기, 이전 포커스 복원, 스크롤 잠금까지 통합하는 것이 좋습니다.

### 3. 설정 화면 코드 분할

마이룸 편집, 차단 관리, 신고 관리는 초기 화면에서 필요하지 않습니다. `React.lazy`와 `Suspense`로 설정 메뉴를 열 때만 불러오도록 분리할 수 있습니다.

### 4. 폴링 통합

토크, 채팅방, 메시지, 최근 사용자가 각각 타이머를 가지고 있습니다. 가시성 변경과 재시도 정책을 공통 폴링 훅 또는 데이터 패칭 계층으로 통합하면 중복 요청과 상태 경쟁을 줄일 수 있습니다.

### 5. 자동 회귀 테스트

다음 흐름은 브라우저 E2E 테스트가 필요합니다.

- 신규 가입 성공·실패
- 토크 작성 실패 후 초안 보존
- 쪽지 버튼 연속 클릭 시 한 방만 열림
- 메시지 전송 실패 후 입력 내용 보존
- 채팅방 나가기 취소·실패·성공
- 프로필 사진 크롭 실패·업로드 실패
- 마이룸 로딩 실패 후 저장 차단
- 출석·광고 요청 실패 후 버튼 복구
- Android 뒤로가기와 모달 닫기
