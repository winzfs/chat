# 플러팅 안전/운영 정책

마지막 갱신: 2026-06-10

이 문서는 플러팅의 정식 운영 전 안전 기준, 신고/차단 처리, 금지 콘텐츠, 운영자 검토 원칙을 정리한 문서입니다.

## 1. 서비스 성격

플러팅은 모바일 환경에서 짧은 토크와 1:1 채팅을 통해 새로운 대화를 시작할 수 있는 소셜 채팅 앱입니다.

현재 앱 설명과 운영 문서는 아래 기준을 일관되게 유지합니다.

```txt
- 20세 이상 이용자 대상
- 토크 기반 대화 시작
- 1:1 채팅 제공
- 이미지 메시지 제공
- 신고/차단 기능 제공
- 부적절한 이용자 제한 가능
```

실제 만남 주선, 성인 콘텐츠 거래, 불법 거래, 금전 요구, 사기성 연락을 조장하지 않습니다.

## 2. 이용 연령 기준

플러팅은 20세 이상 이용자 대상 서비스로 운영합니다.

출시 전 확인할 항목:

- 가입 화면에 20세 이상 제한이 명확히 표시되는지 확인
- Play Store 설명 문구와 앱 내부 문구가 일치하는지 확인
- 이용약관에 20세 이상 이용 제한을 명시
- 콘텐츠 등급 설문 답변과 앱 실제 기능이 충돌하지 않도록 확인

## 3. 금지 콘텐츠

다음 콘텐츠는 작성, 전송, 프로필 등록, 이미지 메시지 전송을 금지합니다.

```txt
- 성적 수치심을 유발하거나 노골적인 성적 표현
- 미성년자 관련 부적절한 대화 또는 이미지
- 불법 촬영물, 합성물, 유포 협박
- 혐오, 차별, 괴롭힘, 모욕
- 스토킹, 협박, 개인정보 요구
- 사기, 투자 권유, 금전 요구, 피싱 링크
- 불법 약물, 도박, 무기, 불법 거래 제안
- 타인의 사진 또는 개인정보 도용
- 반복 광고, 스팸, 외부 연락처 강요
```

운영자는 신고 접수 또는 이상 징후 확인 시 해당 콘텐츠와 계정을 검토할 수 있습니다.

## 4. 신고 처리 흐름

기본 신고 흐름:

```txt
1. 사용자가 채팅방에서 상대방 신고
2. 신고 내용이 reports 테이블에 저장
3. 운영자 또는 moderator가 신고 목록 확인
4. 관련 프로필, 토크, 채팅 메시지, 이미지 메시지 검토
5. 상태를 open → reviewing → closed 순서로 처리
6. 필요 시 차단, 이용 제한, 콘텐츠 삭제, 계정 제한 조치
```

신고 상태:

```txt
open      새 신고
reviewing 검토 중
closed    처리 완료
```

정식 운영 전에는 신고 관리 화면에서 최소한 아래 정보를 확인할 수 있어야 합니다.

- 신고자 ID
- 신고 대상 ID
- 신고 대상 닉네임
- 신고 사유
- 상세 내용
- 관련 채팅방 ID
- 신고 생성 시간
- 처리 상태

## 5. 차단 정책

사용자는 원하지 않는 상대방을 차단할 수 있습니다.

차단 시 기대 동작:

- 차단된 사용자는 최근 접속자 목록에서 제외
- 차단 관계가 있는 사용자와 새 직접 채팅방 생성 제한
- 기존 채팅방에서는 더 이상 대화를 이어가기 어렵도록 UI와 API 동작 정리
- 설정 화면에서 차단 목록 조회와 차단 해제 가능

차단은 사용자의 개인 안전을 위한 기능이며, 운영자 제재와 별도로 작동합니다.

## 6. 운영자 검토 권한

운영자와 moderator는 안전한 서비스 운영을 위해 신고 관련 정보를 확인할 수 있습니다.

검토 가능 정보:

```txt
- 신고 대상 프로필
- 신고 대상 소개글
- 신고 대상 프로필 사진
- 신고 대상 토크 글
- 관련 채팅방 정보
- 관련 채팅 메시지
- 관련 이미지 메시지 URL 또는 메타데이터
```

운영자 권한은 현재 `ADMIN_PROFILE_IDS` 기반 임시 구조입니다. 정식 운영 전에는 `docs/04-auth-and-permissions-plan.md` 기준으로 실제 로그인/토큰 기반 권한 구조로 전환해야 합니다.

## 7. 제재 기준

운영자는 신고 내용과 서비스 피해 정도에 따라 아래 조치를 적용할 수 있습니다.

```txt
1단계: 경고 또는 안내
2단계: 특정 콘텐츠 삭제
3단계: 일정 기간 이용 제한
4단계: 계정 정지
5단계: 심각한 위반 시 영구 제한
```

반복 위반, 미성년자 관련 부적절 행위, 불법 촬영물, 협박, 사기, 개인정보 유출 시도는 강한 제재 대상으로 봅니다.

## 8. 개인정보와 이미지 메시지 원칙

프로필 사진과 이미지 메시지는 사용자 경험을 위한 기능이지만 운영 리스크가 큽니다.

운영 기준:

- 프로필 사진과 이미지 메시지에 민감정보가 포함되지 않도록 안내
- 신고된 이미지 메시지는 운영자가 검토할 수 있음을 약관/개인정보처리방침에 반영
- 부적절한 이미지 전송 신고 시 해당 이미지와 메시지를 확인할 수 있어야 함
- 이미지 저장소 R2 접근 권한과 URL 노출 범위 점검

- [ ] 금지 콘텐츠 기준이 이용약관 또는 운영 정책에 반영됨
